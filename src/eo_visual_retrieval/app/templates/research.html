The experiment path

These are planned stages, not jobs running in the background. Each stage must produce evidence before it changes the default retrieval model.

Next / relevance data

Measure what users mean

Create a versioned prompt set covering land cover, structures, relationships, place/date constraints, and change requests. Judge pooled text, image, and hybrid results on a 0–3 relevance scale; include hard negatives, ambiguous queries and paraphrases.

Track nDCG@10, Recall@10 on the judged pool, judgment coverage, constraint accuracy, no-result rate, and latency. Keep annotators blind to the model and review disagreements.

Planned / corpus expansion

More places and years

Discover Sentinel-2 scenes through STAC, deduplicate acquisitions, inspect chip cloud and snow quality, then acquire bounded batches. Add independent geographies, seasons and sensor conditions.

Freeze spatial and temporal training, development and final partitions before learning. Retain stable item IDs and processing provenance. Resume the separate BigEarthNet acquisition only as an explicit acquisition run.

Planned / controlled comparison

Improve ranking first

Compare frozen RemoteCLIP with other image–text models on the same judged queries. Test DINOv2 as a separate image retrieval branch and rank fusion; tune weights only on development judgments.

Retain exact cosine as the reference. Add approximate indexing when corpus size and measured latency warrant it, reporting recall against exact search.

Conditional / fine-tuning

Adapt only with a valid test

Once enough licensed image–text pairs and relevance judgments exist, compare a frozen baseline with a small adapter or LoRA experiment and, if justified, full contrastive fine-tuning.

Use a fixed data budget, hard negatives, development-only early stopping, and a locked final set. Measure gains, regressions, runtime and memory. The current small temporal diagnostic is not training material for improving its own score.

Planned / temporal evidence

Investigate actual change

For urban expansion, compare aligned observations at the same place across dates, with cloud masks and consistent processing. Validate change labels separately from image similarity.

Make before/after views and the time interval explicit. A single high-scoring scene cannot establish expansion.

Planned / explanation study

Inspect visual sensitivity

Test region occlusion maps: hide patches and measure the score change. Check whether attribution is stable across patch sizes and neutral fills.

Show these as model sensitivity, not causal explanations or object ground truth. Today’s explanations expose ranking arithmetic and verified metadata.

Why these tools

RemoteCLIP provides aligned image and text encoders. OpenCLIP supplies reproducible contrastive-training workflows. LoRA reduces the number of trainable parameters, but cannot replace suitable training data or an independent evaluation.
